# SlowCraft POST

Репозиторий версий игры для **SlowCraft Launcher**. POST 1.05 — версия игры; у лаунчера отдельного номера нет.

Лаунчер читает этот README.md, показывает доступные выпуски и скачивает выбранный ZIP из GitHub Releases. Игры не встроены в лаунчер. Данные и загруженные версии хранятся локально; после установки можно играть без сети.

## POST 1.05 · 15 ноября 2026

- Факелы перенесены наружу: у каждого дома стоит фонарь на опоре. Старые фонари переносятся при посещении деревни, если место снаружи свободно.
- Жители получили более аккуратные модели и одежду профессий; гуляют, смотрят на игрока и прыгают на препятствия с параметрами прыжка игрока.
- Жителей можно бить: 20 здоровья, отбрасывание, короткая защита от повторного удара, бегство и собственные звуки «хм». Здоровье и погибшие жители сохраняются.
- В деревенском сундуке всегда уголь и дерево по 4–10 штук. Рубины: 65% по 1–10; железо: 60% по 1–10; еда: 35% по 1–4; ножницы: 8%; один алмаз: 3%. Ценное снаряжение больше не гарантировано.
- Шанс кандидата деревни уменьшен с 63% до 12% на область 512×512; гарантированной деревни у старта нет. Рельеф дополнительно ограничивает появление.
- Новая генерация и новый лут действуют в новых чанках и ранее не открытых сундуках. Содержимое уже открытых сундуков и постройки сохраняются.
- Механики жителей работают в одиночной игре и у владельца LAN. Синхронизация жителей гостям LAN пока не реализована.
- Лаунчер получает новые и старые версии, даты и описания из GitHub README без замены самого лаунчера. Игры скачиваются отдельно и проверяются по SHA-256.

## Публикация владельцем

1. Создай в GitHub **Releases → Draft a new release** тег `post-1.05` и название `POST 1.05`.
2. Прикрепи **SlowCraft-POST-1.05.zip как один файл**, не распаковывая и не переименовывая. Опубликуй релиз обычным выпуском, не черновиком.
3. Аналогично опубликуй старые архивы с тегами `post-1.04`, `post-1.03`, `post-1.02`, `post-1.01`. Имена ZIP должны совпадать с таблицей. Не используй автоматически создаваемые GitHub архивы Source code вместо файлов игры.
4. Замени README.md в ветке **main** этим файлом. Если пока опубликованы не все старые версии, убери их ID из строки `versions=` ниже, чтобы не показывать неготовые загрузки. Их блоки можно оставить до публикации.
5. Открой лаунчер и нажми «Обновить список». POST 1.05 появится для загрузки. Никаких записей в GitHub эта сборка сама не делает.

## Следующие обновления

Следующий выпуск после POST 1.05 — POST 1.06, затем POST 1.07 и далее. Добавляй отдельный опубликованный релиз и архив игры; сохраняй старые релизы. В блоке ниже добавь новую версию в `versions`, измени `latest` и добавь её поля по образцу. SHA-256 и размер должны относиться к **точному ZIP**, а `jarSha256` — к game.jar внутри него. Описания и строки `changes` читаются лаунчером из этого README. Не меняй строки маркеров, `schema=1` и названия полей. На Windows SHA-256 можно узнать командой `certutil -hashfile ИМЯ.zip SHA256`.
